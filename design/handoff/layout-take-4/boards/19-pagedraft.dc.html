Layout

The body is the stored tree from GET …/files/{path}, drawn as React elements. Nothing is parsed in the browser and no HTML is injected. 1

Every block carries its ID, and every run of text its offset into the document's text, so comments, the diff and selections all count the same way.

Rich blocks

Rich blocks go through a small registry: a fence's language or a node type maps to a component. Diagrams are the first entry, drawn by Pele and loaded only when a page has one.
