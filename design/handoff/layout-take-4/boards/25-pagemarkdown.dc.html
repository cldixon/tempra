16## Layout
17
18The body is the stored tree from `GET …/files/{path}`, drawn as React
19elements. Nothing is parsed in the browser and no HTML is injected.[^reader-src]
20
21Every block carries its ID, and every run of text its offset into the
22document's text; images, footnote markers and hard breaks count as one
23character each, so comments, the diff and selections all count the same way.
24
