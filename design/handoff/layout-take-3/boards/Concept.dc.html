Reader

The concept page: the stored tree drawn as React elements, with previews, the verification diff and comment highlights.

C Claude Code for @cl_dixon ·updated 14 min ago · 2 changes since you verified Review

The reader is the concept page. Its body is the stored tree from GET …/files/{path}, rendered by the app as React elements. Nothing is parsed in the browser, no HTML string is injected, and there is no editor underneath. 1

Layout

The header carries the title, the description and one byline: who wrote it, when, and where it stands with you. History opens from the byline; comments sit in the margin.
